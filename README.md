
## Goal
This repository is for training a decoder only model for Telugu from scratch. 


## Steps
- Prepare a dataset to train the model on
- Preprocess the dataset 
- Train a tokenizer 
- Evaluate the tokenizer and get some statistics on the data
- Choose a model configuration and prepare a model for training
- Train the model
- Evaluate the model and repeat the training until needed
- Upload the model to the hugging face hub
